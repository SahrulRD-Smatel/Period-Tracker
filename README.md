## 🌸 Kilasan & Fitur Spesial untuk Ruru

### 💌 1. Surat Cinta Berpita (*Love Notes*)
Amplop surat cinta beranimasi lembut di Beranda. Ruru bisa membuka pesan-pesan manis dan penyemangat saat sedang lelah atau nyeri, lengkap dengan **bar reaksi cinta instan (💖, 🫂, 🥺, 🌸, 🍫)** untuk saling terhubung dari hati ke hati.

### 🎀 2. Panduan Perhatian Romantis (*Care Guide*)
Di tab Pasangan, ada checklist aksi perhatian nyata yang disesuaikan otomatis dengan fase biologis Ruru hari ini:
- **Saat Haid (Menstrual)**: Pengingat menyajikan teh chamomile/cokelat hangat, menyiapkan bantal pemanas, dan memberi pijatan lembut.
- **Saat PMS (Luteal)**: Menjadi pendengar yang sabar, pelukan hangat tanpa menghakimi, dan menyediakan camilan manis favorit.
- **Saat Ovulasi / Masa Subur**: Ide kencan romantis dan momen kebersamaan yang hangat.

### 👑 3. Desain iOS Mewah (*Dribbble & Figma Award Tier*)
- **Bilah Navigasi Kaca Mengambang (*Floating Frosted-Glass Dock*)**: Efek kaca buram transparan (*backdrop blur 18px*) dengan kapsul navigasi yang halus.
- **Cincin Siklus Ber-Halo (*Glowing Cycle Ring*)**: Busur harian berlekuk indah dengan penanda Hari Ini bercahaya (*glowing pulse aura*).
- **Sentuhan Estetika Coquette**: Permukaan kartu berkilau mutiara (*pearl blush-to-white*), bayangan ganda lembut (*dual-layer depth*), dan pita vektor coquette yang anggun.

### 🔒 4. Privasi Penuh & Keamanan (Offline-First)
- Data tubuh dan siklus Ruru adalah privasi suci: tersimpan aman di perangkat tanpa iklan atau pelacak pihak ketiga.
- Dilengkapi **App Lock (Face ID / Touch ID / PIN)** dengan perlindungan biometrik otomatis saat aplikasi ditutup/resume.
- Pengingat notifikasi lokal pintar di jam 08:00 pagi dengan mode teks diskret/netral.

## 📱 Arsitektur & Teknologi

```
lib/
├── domain/       # Logika murni Dart (prediksi siklus, margin keyakinan, care guide, love notes)
├── application/  # State Management Riverpod 2.x (reaktif & andal)
├── core/         # Sistem Desain (AppColors, kHeading, PinkCard, Floating Dock, PhaseStyle)
└── features/     # Antarmuka Pengguna (Onboarding, Home, Calendar, Stats, Partner, Settings)
```

- **Framework**: Flutter 3.x (Multiplatform: iOS & Android)
- **State Management**: Flutter Riverpod 2.x
- **Icons**: Phosphor Icons Regular & Fill
- **Animations**: `flutter_animate` (smooth micro-interactions)
- **Local Auth**: Biometric / Face ID integration
- **Test Coverage**: 49 unit, domain, scaffold, dan widget tests (100% lulus)

## 🚀 Cara Menjalankan Proyek

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/SahrulRD-Smatel/Period-Tracker.git
   cd Period-Tracker
   ```

2. **Pasang dependensi**:
   ```bash
   flutter pub get
   ```

3. **Jalankan tes & verifikasi kode**:
   ```bash
   flutter analyze
   flutter test
   ```

4. **Jalankan aplikasi di perangkat / simulator**:
   ```bash
   flutter run
   ```
